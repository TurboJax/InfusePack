# InfusePack
The texture pack for TurboJax's Infuse SMP remake.

## For users:
The pack and all its previous versions are available at [https://files.turbojax.org/packs/infuse/](https://files.turbojax.org/packs/infuse/).  For versions before 2.4.5-beta19, you can use those links in your server.properties file.  
From Infuse version 2.4.5-beta19 and above, you no longer need to install the Infuse SMP texture pack.  We do it for you!

## For devs:
Before publishing modified textures, check out [https://compresspng.com/](https://compresspng.com/)  
It got the pack down from 600 KB to 77 KB.
